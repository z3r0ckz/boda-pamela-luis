# Pamela & Luis · 17 de abril de 2027

Invitación web para la boda de Pamela y Luis en Texcoco, Estado de México, con confirmación de asistencia por familia y panel de control de invitados.

- **Invitación:** `index.html?id=enlace-de-la-familia`
- **Panel de los novios:** `admin.html`
- **Hosting:** GitHub Pages · **Datos:** Supabase

Todo lo que hay que editar está en [`js/config.js`](js/config.js). La guía completa (cómo probarlo, conectar Supabase, publicar y usar el panel) está en [PROYECTO.md](PROYECTO.md).

## Probar en local

```bash
npx serve .
```

Sin claves de Supabase el sitio funciona en modo demo con datos de ejemplo guardados en el navegador.
